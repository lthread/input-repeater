# Input Repeater

Записує й повторює рух миші, кліки, прокручування та клавіатуру в Linux із KDE Plasma. Керується глобальними гарячими клавішами, вміє повторювати записи в циклі й працює з трею.

[English version](README.md)

## Можливості

- **Глобальні гарячі клавіші** запускають і зупиняють запис та відтворення. Це може бути одна клавіша, комбінація на кшталт `Ctrl+Alt+R` або бічна кнопка миші.
- **Точні до пікселя позиції курсора** програма отримує від KWin, тож на відтворення не впливає прискорення миші. Відтворювати можна й від поточного положення курсора.
- **Цикли:** N разів або до зупинки, з паузою між повторами й швидкістю від 0,1× до 10×.
- **Вибір, що записувати:** рух миші, кліки й колесо, клавіатура.
- **Бібліотека записів:** перейменування та видалення у смітник.
- **Безпечна зупинка:** відтворення зупиняється, щойно ви рухнете мишею чи натиснете клавішу.
- **Стан наживо:**
  - іконка в треї змінюється разом зі станом і анімується під час запису та відтворення;
  - прогрес відтворення («Повтор 2 з 5 · 43%») видно у вікні, у підказці трею та на панелі задач.
- **Мова інтерфейсу:** англійська або українська.

## Вимоги

- Linux із **KDE Plasma 6**, Wayland або X11.
- Python 3 з `python-evdev`, `dbus-python`, `PyGObject` і `PyQt6`, а також `libnotify` (`notify-send`).
- Ваш користувач має бути в групі `input`, щоб читати клавіатури й миші.
- Доступ до `/dev/uinput` для відтворення. Його дає udev-правило з репозиторію.

Інші середовища (GNOME, Sway, Hyprland), Plasma 5, Windows і macOS не підтримуються. Точні позиції курсора надає саме KWin, а введення йде через evdev/uinput, які є лише в Linux.

## Встановлення

### Arch Linux і похідні

З AUR (після публікації):

```bash
yay -S input-repeater
```

Або зібрати з цього репозиторію:

```bash
git clone https://github.com/lthread/input-repeater.git
cd input-repeater
makepkg -si
```

### Інші дистрибутиви (з вихідного коду)

Встановіть залежності:

```bash
# Fedora
sudo dnf install python3-evdev python3-dbus python3-gobject python3-pyqt6 libnotify
# openSUSE Tumbleweed
sudo zypper install python3-evdev python3-dbus-python python3-gobject python3-PyQt6 libnotify-tools
# KDE neon / Kubuntu
sudo apt install python3-evdev python3-dbus python3-gi python3-pyqt6 libnotify-bin
```

Потім отримайте код і дозвольте сеансу створювати віртуальні пристрої введення:

```bash
git clone https://github.com/lthread/input-repeater.git
cd input-repeater
sudo install -Dm644 60-input-repeater.rules /etc/udev/rules.d/60-input-repeater.rules
sudo udevadm control --reload && sudo udevadm trigger --sysname-match=uinput
```

Запуск: `python3 gui.py`. Скрипт без вікна: `python3 input_repeater.py`.

### Останній крок (усі дистрибутиви)

```bash
sudo usermod -aG input $USER
```

Щоб група почала діяти, вийдіть із сеансу й увійдіть знову.

> Учасники групи `input` можуть читати всі клавіатури й миші. Без цього глобальний запис на Wayland неможливий.

## Використання

Запустіть **Input Repeater** з меню й натисніть **Запустити**. Гарячі клавіші за замовчуванням:

- **F9**: почати або зупинити запис. Кожен запис зберігається окремо й одразу стає активним.
- **F10**: відтворити активний запис. Повторне натискання зупиняє відтворення.

Закрите вікно ховається в трей. Вийти можна з меню іконки, тоді зупиниться й скрипт.

## Налаштування

Усе налаштовується у вікні:

| Що | Коли діє |
|---|---|
| Активний запис, що записувати, цикл, пауза, швидкість, режим руху, безпечна зупинка | з наступного запису чи відтворення, без перезапуску |
| Гарячі клавіші, сповіщення | після перезапуску скрипта (поки він працює, поля заблоковані) |
| Мова інтерфейсу | одразу; повідомлення скрипта зміняться після його перезапуску |

**Гарячі клавіші.** Клацніть у поле й натисніть клавішу, комбінацію або бічну кнопку миші. Поки тримаєте модифікатори, у полі видно `CTRL+ALT+…`. Якщо задати одну комбінацію для обох дій, вони обміняються місцями.

**Рух миші під час відтворення:**
- *Точні координати екрана*: курсор проходить тими самими точками екрана, що й під час запису.
- *Від поточного положення курсора*: увесь запис зсувається так, щоб почався там, де зараз курсор.

**Де лежать файли:**
- налаштування: `~/.config/input-repeater/config.json`;
- записи: `~/.local/share/input-repeater/macros/`.

Видалені записи потрапляють у смітник.

## Як це працює

- Клавіші, кнопки миші та колесо читаються напряму з `/dev/input` (evdev), тому запис глобальний.
- Точну позицію курсора повідомляє KWin через тимчасовий KWin-скрипт. Він працює лише під час запису та на мить на старті відтворення від поточного положення курсора.
- Відтворення йде через два віртуальні пристрої `uinput`: клавіатуру та абсолютний вказівник.

## Обмеження

- Гарячі клавіші не перехоплюються, тож активне вікно теж їх отримує. Обирайте комбінації, які вам не заважають.
- Комбінації, зайняті глобальними скороченнями KDE, не можна вписати в поле гарячої клавіші.
- Тап по тачпаду й прокручування двома пальцями є жестами, тому не записуються. Фізичний клік тачпадом записується.
- Перо графічного планшета записується як рух і лівий клік.
- Якщо після запису змінилося розташування моніторів, точні координати не збігатимуться.
- На Wayland, де з'явиться вікно, вирішує KWin. Щоб вікно запам'ятовувало положення, додайте правило вікна KWin для класу `input-repeater` з параметром *Положення → Запам'ятати*.
